3.1

Die Additionsreaktion

Addition▾
Definition

Mehrfachbindungen (C=C oder C≡C) werden aufgespalten, um Atome/Atomgruppen anzulagern. Aus zwei Molekülen entsteht ein neues — nichts wird abgespalten.

Merksatz: Aus zwei wird eins – nichts geht verloren.
Nachweis — Bromwasserprobe
  • Bromwasser ist rotbraun
  • Positive Probe → Entfärbung (farblos)
  • Weist Alkene & Alkine nach (Mehrfachbindungen)
  • Schütteln nötig → vergrößert Kontaktfläche zwischen den Phasen
Reaktionsmechanismus — Brom an Ethen (3 Schritte)
  1. Polarisierung des Brommoleküls — π-Elektronen stoßen das nähere Br ab → δ⁺/δ⁻ entstehen
  2. Cyclischer Übergangszustand — Br⁺ lagert sich an beide C-Atome an → Bromonium-Ion + Br⁻
  3. Addition des Bromid-Ions — Br⁻ greift von der gegenüberliegenden Seite an
CH₂=CH₂ + Br₂ → CH₂Br–CH₂Br // 1,2-Dibromethan (farblos)
Alkin → 2× Addition möglich
Ethin + Br₂ → 1,2-Dibrometen (Zwischenprod.) → + Br₂ → 1,1,2,2-Tetrabromethan
3.2

Radikalische Substitution

Substitution▾
Definition

Atome/Atomgruppen werden durch andere ersetzt. Z. B. H-Atom durch Br-Atom. Mechanismus = Radikalkettenreaktion.

3 Phasen
  1. Startreaktion — durch Licht/Wärme (homolytische Spaltung)
    Br–Br → (hν) 2 Br• // 2 Brom-Radikale entstehen
  2. Kettenreaktion — läuft selbstständig weiter (Schleife!)
    R–CH₃ + Br• → R–CH₂• + H–Br // Heptyl-Radikal
    R–CH₂• + Br₂ → R–CH₂–Br + Br• // 1-Bromheptan + neues Radikal → von vorne
  3. Abbruchreaktion — wenn zwei Radikale zusammentreffen
    R• + R• → R–R  |  R• + Br• → R–Br  |  Br• + Br• → Br₂
Merkmale
  • Reaktion stark exotherm
  • Viele Nebenprodukte durch verschiedene Abbruchreaktionen
  • FCKW → bauen Ozonschicht ab → seit 1989 verboten
Beispiel: Methan + Chlor → Trichlormethan (CHCl₃)
Start: Cl₂ → (hν) 2 Cl•
Kette 1: CH₄ + Cl• → CH₃• + HCl
Kette 2: CH₃• + Cl₂ → CH₃Cl + Cl• // → wiederholen bis CHCl₃
Abbruch: Cl• + Cl• → Cl₂
3.3

Oxidation von Ethanol

Redox▾
Abbauweg im Körper
Ethanol → (Ox) Ethanal → (Ox) Ethansäure (Essigsäure)
// Ethanal = Zellgift → Übelkeit, Kopfschmerzen, Gedächtnislücken
Was passiert? (Reagenz: CuO)
  • Oxidation: Ethanol → Ethanal (OZ am C steigt)
  • Reduktion: Cu²⁺ → Cu⁰ (nimmt 2 Elektronen auf)
Gesamtgleichung Ethanol → Ethanal
CH₃–CH₂–OH + CuO → CH₃–CHO + Cu + H₂O
Teilgleichungen
Ox: CH₃–CH₂–OH + 2H₂O → CH₃–CHO + 2H₃O⁺ + 2e⁻
Red: CuO + 2e⁻ + 2H₃O⁺ → Cu + 3H₂O
Weiteroxidation → Ethansäure
CH₃–CHO + CuO → CH₃–COOH + Cu
3.4

Oxidation von Alkanolen

Redox▾
Übersicht nach Alkohol-Typ
TypProdukt 1Produkt 2
Primär (–OH am Kettenende)Alkanal (Aldehyd)Alkansäure (Carbonsäure)
Sekundär (–OH in der Mitte)Alkanon (Keton)— nicht weiter oxidierbar
Tertiär (3× C gebunden)Keine Oxidation möglich
Warum? Kein H-Atom direkt am C mit der funktionellen Gruppe → Oxidation nicht möglich.
Beispiel Propan-2-ol (sekundär) → Aceton
CH₃–CHOH–CH₃ + CuO → CH₃–CO–CH₃ + Cu + H₂O
// Propan-2-ol → Propan-1-on (Aceton / Keton)
Oxidationszahl bestimmen (4 Schritte)
  1. C-Atom der funktionellen Gruppe finden
  2. EN-Werte der Bindungspartner: C=2,5 · H=2,1 · O=3,5
  3. Elektronen dem elektronegativeren Atom zuordnen
  4. OZ = 4 − (zugeordnete Elektronen)
Oxidation = OZ steigt  |  Reduktion = OZ sinkt
3.5

Kondensationsreaktion / Esterbildung

Kondensation▾
Definition

Zwei Moleküle verbinden sich unter Abspaltung von H₂O. Die Veresterung ist eine Kondensationsreaktion.

Veresterung
Carbonsäure + Alkohol → (H₂SO₄) Ester + Wasser
// H₂SO₄ = Katalysator
Benennung
[Säurename] + "-" + [Alkylrest] + "-ester"

Essigsäure + Ethanol → Essigsäure-ethyl-ester
Propansäure + Butanol → Propansäure-butyl-ester
Methansäure + Ethanol → Methansäure-ethyl-ester
Fruchtester
EsterAroma
EssigsäurepentylesterBanane
ButansäureethylesterAnanas
ButansäuremethylesterApfel
AmeisensäureethylesterRum
EssigsäureoctylesterOrange
3.6

Ester und ihre Eigenschaften

Eigenschaften▾
Funktionelle Gruppe

Ester-Gruppe: –COO– (polare Gruppe, aber mit unpolaren Alkyl-Resten an beiden Seiten)

Wechselwirkungen
  • LONDON-Dispersionskräfte (dominieren bei langen Alkyl-Resten)
  • Dipol-Dipol-Wechselwirkungen (durch polare Estergruppe)
  • Keine Wasserstoffbrücken (keine OH-Gruppe mehr!)
Fruchtester vs. Wachsester
Fruchtester (kurzkettig)
  • Schwer wasserlöslich
  • Intensive Gerüche, farblos
  • Niedrige Siedetemperatur
  • Leicht flüchtig & entzündlich
  • Dipol-Dipol überwiegt
Wachsester (langkettig)
  • Nicht wasserlöslich
  • Bei Raumtemp. fest
  • Mittlere Siedetemperatur
  • Leichter Geruch
  • London-Kräfte dominieren
Vergleich Löslichkeit & Siedetemperatur
Löslichkeit in H₂O: Ester < Ethanol < Essigsäure
Siedetemperatur: Ester < Ethanol < Essigsäure
4.1

Glycerin (Glycerol)

Biomolekül▾
Grundinfo
  • Lebensmittelzusatzstoff E422 = Feuchthaltemittel
  • Mehrwertiger Alkohol = 3 OH-Gruppen (Triol)
  • Griech. glykeros = süß
Eigenschaften (wegen 3× OH-Gruppe)
  • Bildet Wasserstoffbrücken zu H₂O-Molekülen
  • Dickflüssig (viskos), hygroskopisch (wasseranziehend)
  • Sehr gut wasserlöslich
  • Hohe Siedetemperatur: 290 °C (Propanol nur 97 °C)
Verwendung

Feuchthaltemittel (Tabak, Cremes, Salben), Seifenblasen, Süßungsmittel, Nitroglycerin (Sprengstoff + Herzmedikament in kleiner Dosis)

4.2

Fette – Aufbau und Eigenschaften

Biomolekül▾
Aufbau

Fette = Triester aus Glycerin + 3 Fettsäuren → Dreifachveresterung (3× Kondensationsreaktion)

Glycerin (3× OH) + 3× Fettsäure (–COOH) → Tri-Fettsäure-Glycerin-Ester + 3 H₂O
Fest vs. Flüssig
Feste Fette (z.B. Butter, 28–35°C)
  • Gesättigte Fettsäurereste
  • Nur C–C-Einfachbindungen
  • Gerade Ketten → lagern sich gut an
  • Starke London-Kräfte
Flüssige Fette / Öle
  • Ungesättigte Fettsäurereste (C=C)
  • Knicke in den Ketten
  • Schlechtere Anlagerung
  • Schwächere London-Kräfte → niedrigerer Schmelzpunkt
Eigenschaften allgemein
  • Lipophil + hydrophob (lange unpolare Fettsäurereste)
  • Kein fester Schmelzpunkt (Gemisch verschiedener Triester)
  • Fette Öle zersetzen sich beim Erhitzen → bilden Propenal
  • Fettbrand NICHT mit Wasser löschen → Stichflamme!
