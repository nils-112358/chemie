3.1

Die Additionsreaktion

Addition ▾
```
Definition
Mehrfachbindungen (C=C oder C≡C) werden aufgespalten, um Atome oder Atomgruppen anzulagern. Es entsteht ein neues Molekül — nichts geht verloren.
Merksatz: Aus zwei wird eins – nichts geht verloren.
Nachweis — Bromwasserprobe
  • Bromwasser ist rotbraun
  • Bei positiver Probe → Entfärbung (farblos)
  • Weist Alkene & Alkine nach (Mehrfachbindungen)
  • Schütteln nötig → vergrößert Kontaktfläche zwischen den Phasen
Reaktionsmechanismus — Brom an Ethen (3 Schritte)
  1. Polarisierung des Brommoleküls — π-Elektronen des Alkens stoßen das näherliegende Br-Atom ab → δ⁺/δ⁻-Ladungen entstehen
  2. Bildung eines cyclischen Übergangszustands — Br⁺ lagert sich an beide C-Atome an → Bromonium-Ion + Bromid-Ion entsteht
  3. Addition des Bromid-Ions — Br⁻ greift von der gegenüberliegenden Seite an
CH₂=CH₂ + Br₂ → CH₂Br–CH₂Br // 1,2-Dibromethan (farblos)
Alkin → 2× Addition möglich
Ethin + Br₂ → 1,2-Dibroметhan (Zwischenprod.: CHBr=CHBr = 1,2-Dibromethен) → dann nochmal Br₂ → CHBr₂–CHBr₂
```
3.2

Radikalische Substitution

Substitution ▾
```
Definition
Atome/Atomgruppen werden an einem Molekül durch andere ersetzt (substituiert). Z. B. H-Atom durch Br-Atom.
3 Phasen — Radikalkettenreaktion
  1. Startreaktion — durch Licht/Wärme
    Br–Br →hν 2 Br• // homolytische Spaltung → 2 Radikale
  2. Kettenreaktion — läuft selbstständig weiter
    R–CH₃ + Br• → R–CH₂• + H–Br // Schritt 1: Heptyl-Radikal
    R–CH₂• + Br–Br → R–CH₂–Br + Br• // Schritt 2: 1-Bromheptan + neues Radikal
  3. Abbruchreaktion — wenn zwei Radikale aufeinandertreffen
    R• + R• → R–R
    R• + Br• → R–Br
    Br• + Br• → Br–Br
Wichtige Merkmale
  • Reaktion stark exotherm (Alkane stabiler als Alkene → weniger aktiv → braucht Aktivierungsenergie)
  • Viele Nebenprodukte durch verschiedene Abbruchreaktionen
  • FCKW = Fluorchlorkohlenwasserstoffe → bauen Ozonschicht ab → seit 1989 verboten
Aufgaben-Beispiel: Methan + Chlor → Trichlormethan
Start: Cl–Cl →hν 2 Cl•
Kette 1: CH₄ + Cl• → CH₃• + HCl
Kette 2: CH₃• + Cl₂ → CH₃Cl + Cl•
// Wiederholen bis CH₂Cl₂, CHCl₂•, CHCl₃ (Trichlormethan)
```
3.3

Oxidation von Ethanol

Redox ▾
```
Abbauweg im Körper
Ethanol →Ox Ethanal →Ox Ethansäure (Essigsäure)
// Ethanal = Zellgift → Übelkeit, Kopfschmerzen, Gedächtnislücken
Reagenz: Kupfermonooxid (CuO)
  • Oxidation: Ethanol → Ethanal (Erhöhung der Oxidationszahl am C)
  • Reduktion: Cu²⁺ in CuO → elementares Cu (Erniedrigung der Ox-Zahl)
Gesamtgleichung
CH₃–CH₂–OH + CuO → CH₃–CHO + Cu + H₂O
// Ethanol + Kupfermonooxid → Ethanal + Kupfer + Wasser
Teilgleichungen
Oxidation: CH₃–CH₂–OH + 2H₂O → CH₃–CHO + 2H₃O⁺ + 2e⁻
Reduktion: CuO + 2e⁻ + 2H₃O⁺ → Cu + 3H₂O
Weiteroxidation zu Ethansäure
CH₃–CHO + CuO → CH₃–COOH + Cu
// Ethanal + CuO → Essigsäure + Kupfer
```

Oxidation von Alkanolen

Redox ▾
```
Übersicht nach Alkohol-Typ
TypProdukt 1Produkt 2Warum?
Primär (–OH am Endstück)Alkanal (Aldehyd)Alkansäure (Carbonsäure)H am C der funk. Gruppe vorhanden
Sekundär (–OH in der Mitte)Alkanon (Keton)— (nicht weiter)noch ein H am C
Tertiär (–OH, 3× C gebunden)Keine Oxidation möglichKein H direkt am C mit OH
Beispiel — Propan-2-ol (sekundär) → Aceton
CH₃–CHOH–CH₃ + CuO → CH₃–CO–CH₃ + Cu + H₂O
// Propan-2-ol → Propan-1-on (Aceton)
Oxidationszahlen bestimmen (Fachmethode)
  1. C-Atom der funktionellen Gruppe finden
  2. EN-Werte aller Bindungspartner aufschreiben (C=2,5 / H=2,1 / O=3,5)
  3. Elektronen nach EN-Differenz zuordnen (höheres EN → bekommt beide)
  4. Zugeordnete Elektronen zählen → OZ = 4 − Elektronen
Oxidation = OZ steigt · Reduktion = OZ sinkt
```

3.6

Ester und ihre Eigenschaften

Eigenschaften ▾
```
Funktionelle Gruppe
Ester-Gruppe: –COO– (polare Gruppe, aber zwei unpolare Alkyl-Reste drumherum)
Wechselwirkungen zwischen Ester-Molekülen
  • LONDON-Dispersionskräfte (dominieren bei langen Alkyl-Resten)
  • Dipol-Dipol-Wechselwirkungen (durch polare Estergruppe)
  • ⚠ Keine Wasserstoffbrücken (keine OH-Gruppe mehr!)
Fruchtester vs. Wachsester
Fruchtester (kurzkettíg)
  • Schwer wasserlöslich
  • Intensive Gerüche
  • Niedrige Siedetemperatur
  • Leicht flüchtig, leicht entzündlich
  • Dipol-Dipol überwiegt
Wachsester (langkettig)
  • Nicht wasserlöslich
  • Bei Raumtemp. fest
  • Mittlere Siedetemperatur
  • Leichter Geruch
  • London-Kräfte dominieren
Löslichkeit (Faustregel)
Kurze Alkyl-Reste → polare Estergruppe dominiert → eher hydrophil
Lange Alkyl-Reste → unpolarer Charakter → lipophil, hydrophob
Reihenfolge Löslichkeit in Wasser: Ester < Ethanol < Essigsäure
Reihenfolge Siedetemp.: Ester < Ethanol < Essigsäure
```
4.1

Glycerin (Glycerol)

Biomolekül ▾
```
Grundinfo
  • Lebensmittelzusatzstoff E422, Feuchthaltemittel
  • Mehrwertiger Alkohol (3 OH-Gruppen → Triol)
  • Griech.: glykeros = süß
Eigenschaften (wegen 3× polarer OH-Gruppe)
  • Kann Wasserstoffbrücken zu Wasser-Molekülen ausbilden
  • Dickflüssig (viskos)
  • Sehr gut wasserlöslich
  • Hygroskopisch (wasseranziehend)
  • Hohe Siedetemperatur: 290 °C (Propanol: 97 °C)
Verwendung
Feuchthaltemittel (Tabak, Cremes), Seifenblasen, Süßungsmittel, Nitroglycerin (Sprengstoff + Herzmedikament)
```
4.2

Fette – Aufbau und Eigenschaften

Biomolekül ▾
```
Aufbau
Fette = Triester aus Glycerin + 3 Fettsäuren (Dreifachveresterung = 3× Kondensationsreaktion)
Glycerin (3× OH) + 3× Fettsäure (–COOH) → Tri-Fettsäure-Glycerin-Ester + 3 H₂O
Fest vs. Flüssig
Feste Fette (z.B. Butter, 28–35°C)
  • Gesättigte Fettsäurereste
  • Nur C–C-Einfachbindungen
  • Gerade Ketten → lagern sich gut an
  • Starke London-Kräfte
Flüssige Fette / Öle (z.B. Leinöl, −20°C)
  • Ungesättigte Fettsäurereste (C=C)
  • Knicke in den Ketten
  • Schlechte Anlagerung
  • Schwächere London-Kräfte
  • Niedrigerer Schmelzbereich
Eigenschaften
  • Lipophil + hydrophob (lange unpolare Fettsäurereste)
  • Kein fester Schmelzpunkt (Gemisch versch. Triester-Moleküle)
  • Fette Öle zersetzen sich beim Erhitzen → bilden Propenal (riecht unangenehm)
  • Fettbrand NICHT mit Wasser löschen → Stichflamme!
Wichtige Fettsäuren
NameFormelArt

ÖlsäureC₁₇H₃₃COOHeinfach ungesättigt
LinolsäureC₁₇H₃₁COOHmehrfach ungesättigt
```
